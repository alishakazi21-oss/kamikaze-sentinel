# ASTRA VEER - System Architecture (SIH 247)

## Overview
**ASTRA VEER** is an AI-Enabled Drone & Counter-Drone Threat Simulation Trainer built for unit-level operational readiness without requiring heavy gaming rigs or GPU clusters.

```
                    +------------------------------------+
                    |        React 19 + TypeScript       |
                    |   Tactical Radar PPI + 3D View     |
                    |   Setup | Telemetry | AAR Engine   |
                    +-----------------+------------------+
                                      | REST / WebSockets
                    +-----------------v------------------+
                    |        FastAPI Core Backend        |
                    |   Scenario Engine | Adaptive Alg   |
                    |   Scoring Tree | Scikit-Learn AI   |
                    +-----------------+------------------+
                                      |
                     +----------------v-----------------+
                     |     TrackSource (Abstraction)    |
                     |  Synthetic Radar & EO Generation |
                     +----+---------------+-------------+
                          |               |             |
               NativeSimSource     ReplaySource   AirSimBridgeSource
               (Deterministic 2D/  (JSON Replay   (Optional Bridge to
                3D Swarms & Decoy)  Telemetries)   Cosys-AirSim UE5)
```

## Core Tenets
1. **Lightweight Unit-Level Deployment**: Fully runs offline on standard defense laptops with zero cloud or GPU dependencies.
2. **Decoupled Sensor Modeling**: Whether targets are generated by `NativeSimSource`, loaded from `ReplaySource`, or streamed from `AirSimBridgeSource`, tracks pass through a unified **Sensor Model** that introduces realistic radar clutter, noise, dropout, and night-vision optical degradation.
3. **Deterministic Seed Control**: Every procedural scenario is driven by a pseudo-random seed. The same seed generates identical flight vectors, allowing reproducible benchmarking and side-by-side trainee evaluation.
4. **Explainable AI & Decision-Tree Scoring**: Scoring is driven by an explicit 3-pillar decision tree (Detection Latency, Classification Accuracy, Decision Quality). The AI assistant uses scikit-learn models to assist trainees and provides explainable telemetry rationale.
